# Aplikasi Manajemen Proyek Berbasis Website

Aplikasi manajemen proyek berbasis website yang dikembangkan untuk membantu pengguna dalam mengelola workspace, project, task, serta mendukung kolaborasi antaranggota tim.

## Deskripsi

Aplikasi ini menyediakan fitur untuk mengelola proyek secara terstruktur mulai dari pembuatan workspace, pengelolaan project dan task, pengaturan anggota tim, hingga pemantauan status pekerjaan.

Aplikasi juga menyediakan fitur notifikasi dan pengingat deadline untuk membantu pengguna mengetahui task yang mendekati batas waktu.

## Fitur Utama

- Login dan autentikasi pengguna
- Workspace
- Manajemen project
- Manajemen task
- Manajemen anggota tim
- Kanban board
- Pengaturan status task
- Kalender project
- Notifikasi deadline
- Pengingat task berdasarkan Decision Tree
- Kolaborasi antaranggota dalam workspace

## Teknologi yang Digunakan

- **Next.js** – framework utama aplikasi web
- **React** – membangun antarmuka pengguna
- **TypeScript** – penulisan kode dengan tipe data
- **Hono** – pembuatan API
- **Appwrite** – database dan layanan backend
- **React Query** – pengelolaan data dari API
- **Tailwind CSS** – styling antarmuka
- **shadcn/ui** – komponen antarmuka
- **Zod** – validasi data
- **Git & GitHub** – version control dan penyimpanan repository
